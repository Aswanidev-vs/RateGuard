Docker guide

One multi-stage image builds two binaries: /app/rateguard and /app/demo. Compose starts Caddy, the proxy, and the demo upstream on a private network.

1

Prepare the environment

Copy the template and replace both placeholders with random secrets. .env is gitignored.

Git Bash
cp .env.example .env
ADMIN_KEY="$(openssl rand -base64 48)"
SESSION_KEY="$(openssl rand -base64 48)"
sed -i "s|^ADMIN_API_KEY=.*|ADMIN_API_KEY=${ADMIN_KEY}|" .env
sed -i "s|^SESSION_SECRET=.*|SESSION_SECRET=${SESSION_KEY}|" .env

Do not commit .env. Use openssl rand -base64 48 or the .NET random generator in PowerShell.

2

Build and start the stack

Any shell
docker compose up -d --build
docker compose ps
docker compose logs -f api

Caddy publishes ports 80 and 443. The API and demo services stay internal. Dashboard: http://localhost/dashboard.

3

Smoke test

Git Bash
curl -s http://localhost/healthz
KEY=$(curl -s -X POST http://localhost/api/v1/tenants \
  -H "Authorization: Bearer $ADMIN_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"name":"Demo","email":"demo@example.com","limit_rpm":60,"burst":5}' \
  | python -c 'import json,sys; print(json.load(sys.stdin)["api_key"])')
curl -i -H "Authorization: Bearer $KEY" http://localhost/proxy/quote
4

Teardown

Any shell
docker compose down -v

The app flushes buffered usage on SIGTERM, so allow the 30-second grace period before forcing anything.
