Security audit

Source-first review of the Go app, containers, Terraform, and CI. This project is a learning implementation, not production hardening.

Full evidence and remediation detail live in docs/SECURITY-AUDIT.md. The confirmed fixes are summarized here.

IDSeverityIssueFix
SEC-01HighDynamoDB usage expression bound :sum_latency but referenced :sum_latency_msCorrected key; added expression placeholder regression test
SEC-02MediumProxy dot-segment traversal toward upstream base pathsDot-segment guard plus chi CleanPath, with test
SEC-03MediumUnbounded login/admin attempt-map growthCapped map with eviction
SEC-04MediumCI role allowed SSM commands against any instanceScoped to the created EC2 instance ARN
SEC-05LowCacheable error pages and demo upstream without CSPno-store and a strict CSP added

Verified controls

  • Raw API keys are generated with crypto/rand, hashed with SHA-256, shown once, and never logged.
  • Dashboard mutations require a signed session cookie, CSRF token, and an origin check.
  • Tenant keys are stripped before requests reach the upstream.
  • CI uses GitHub OIDC with no static AWS credentials, restricted to main.
  • ECR images run as UID 65532 on distroless with a read-only root filesystem.

Still needs operator validation: Terraform apply, ECR push, Trivy scan, OIDC trust, and a live deployment smoke test. Nothing was applied to AWS by the coding agent.
