Why RateGuard?

All the essentials you need to run APIs safely, fairly, and cost-effectively.

Token buckets, not guesswork

Each tenant gets a bucket: capacity is burst, refill is limit_rpm / 60 tokens per second. Excess requests are rejected before they reach your API.

429 · Retry-After: 12

API keys with real scoping

Issue ag_live_... keys per tenant, store only SHA-256 hashes, and resolve quotas by prefix lookup with a bounded TTL cache.

POST /api/v1/tenants

AWS spend anomalies

An hourly Lambda compares EstimatedCharges against a seven-day baseline. Breaches become DynamoDB records and SNS alerts.

current > baseline + 2σ

HTTP-native proxy

No SDK in your service: forward /proxy/* and read X-RateLimit-* on the response. Health checks and graceful shutdown included.
