Run RateGuard locally

Start the proxy, start the demo upstream, issue a tenant key, and watch the token bucket return its first 429. No AWS account needed for this path.

The Go process listens on localhost:8080. A plain go run does not read .env, so you export the variables in your shell first.

1

Start the RateGuard server

From the repository root, in Git Bash:

Git Bash
export ADMIN_API_KEY="dev-admin-key-1234567890"
export SESSION_SECRET="dev-session-secret-12345678901234567890"
export STORE_BACKEND=memory
export PROXY_UPSTREAM_URL=http://localhost:8090
go run ./cmd/server

Or in PowerShell:

PowerShell
$env:ADMIN_API_KEY="dev-admin-key-1234567890"
$env:SESSION_SECRET="dev-session-secret-12345678901234567890"
$env:STORE_BACKEND="memory"
$env:PROXY_UPSTREAM_URL="http://localhost:8090"
go run ./cmd/server

Dashboard: http://localhost:8080/dashboard. Health check: http://localhost:8080/healthz. Port 80 is only used when you run the Docker Compose stack with Caddy.

2

Start the demo upstream

In a second terminal, run the quote service that sits behind the proxy. It listens on :8090.

Terminal 2
go run ./examples/quote
3

Issue a tenant key and flood the bucket

Create a tenant with the admin key, then send more requests than its burst allows.

Git Bash
KEY=$(curl -s -X POST http://localhost:8080/api/v1/tenants \
  -H "Authorization: Bearer $ADMIN_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"name":"Demo","email":"demo@example.com","limit_rpm":60,"burst":5}' \
  | python -c 'import json,sys; print(json.load(sys.stdin)["api_key"])')

for i in $(seq 1 20); do
  curl -s -o /dev/null -w "%{http_code}\n" \
    -H "Authorization: Bearer $KEY" \
    http://localhost:8080/proxy/quote
done
  • The first 5 requests return 200 and a random quote.
  • Later requests return 429 with Retry-After.
  • The dashboard shows allowed, blocked, and p95 latency for the tenant.
4

Sign in to the dashboard

Open http://localhost:8080/dashboard and sign in with the admin key you exported:

Admin key
dev-admin-key-1234567890

Tenant keys beginning with ag_live_ cannot sign in here — they are for /proxy/* only.

5

Prefer Docker?

Copy the environment template, generate real secrets, and bring up Caddy, the app, and the demo upstream together.

Git Bash
cp .env.example .env
# Generate two secrets with: openssl rand -base64 48
# Then edit .env: ADMIN_API_KEY=... and SESSION_SECRET=...
docker compose up -d --build

With Compose, Caddy serves http://localhost on port 80. See the Docker guide for PowerShell commands and TLS setup.
