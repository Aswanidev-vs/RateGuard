Quick start

Run the Go server and demo upstream, issue a tenant key, and trigger your first 429. Includes Git Bash and PowerShell commands.

go run ./cmd/server

Docker guide

Build the multi-stage distroless image, run the compose stack, configure Caddy, and clean up with docker compose down -v.

docker compose up -d --build

API reference

Base path /api/v1. Admin routes use Authorization: Bearer <admin key>; tenant routes use an ag_live_... key.

MethodPathAuthPurpose
POST/tenantsadminCreate a tenant; returns the one-time API key
GET/tenantsadminList tenants
GET/tenants/{id}adminRead a tenant; hash is never returned
PATCH/tenants/{id}adminChange limit, burst, or enabled state
DELETE/tenants/{id}adminSoft-delete (disable) a tenant
GET/tenants/{id}/usageadmin or tenantallowed, blocked, avg and p95 latency
ANY/proxy/*tenantRate-limited passthrough to the upstream
GET/healthz, /readyznoneLiveness and store readiness

Proxy response headers

HeaderMeaning
X-RateLimit-LimitBucket capacity for this tenant
X-RateLimit-RemainingWhole tokens left after this request
X-RateLimit-ResetEpoch seconds until the bucket is full
Retry-AfterSeconds until one token is available, on 429 only
